# Подключение и расходы

## Возможная архитектура

YCLIENTS/выгрузка → планировщик и журнал событий → SIP-телефония → голосовой агент Yandex AI Studio → результаты в журнал и YCLIENTS → уведомления в закрытый Telegram/MAX → отчёт.

В первой версии оформление новой записи остаётся у администратора. Автоматическое бронирование активируется только после подтверждения API и бизнес-правил.

## Что требуется от салона до внедрения

- Учётные записи YCLIENTS, Yandex Cloud, телефонии и выбранного мессенджера администратора. Секреты не сохранять в репозитории.
- Актуальная выгрузка потерянных клиентов и правила обработки персональных данных.
- Список услуг, цены, мастера, условия промокодов, правила переноса и отмены.
- Допустимые часы и основания обзвона, лимит попыток и интервалы повторов.
- Бюджет на звонки и согласованная тестовая группа.

## Ежемесячные расходы

Точную сумму нельзя назвать без числа звонков, средней длительности разговора и тарифа телефонии. Ориентир для постоянного сервера в Yandex Compute Cloud — **от 1 659 ₽/месяц** за минимальную конфигурацию по публичной странице Яндекса на октябрь 2026 года. К этому отдельно добавляются расходы на исходящие минуты SIP-телефонии, голосовой Realtime API и, при необходимости, платные интеграции YCLIENTS/Wahelp. Для пилота возможна иная конфигурация, её надо посчитать в калькуляторе после выбора провайдера.

Источник по серверу: https://yandex.cloud/ru/services/compute

Yandex Cloud сообщает, что SIP-подключение голосового агента находится в режиме Preview и выполняется специалистами по заявке; доступность и коммерческие условия нужно подтвердить у поддержки до обещания даты полноценного запуска.

Источник по SIP: https://yandex.cloud/ru/blog/voice-agent-and-other-updates
